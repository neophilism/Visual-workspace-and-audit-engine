# Private source-linked caption review

`./caption-review` exports graph projection and static private transcript rendering. The authenticated host supplies clean, purpose-authorized original caption bytes, the separately authorized media binding, and the actual stored derivative reference/hash. The view re-runs the pinned Processing WebVTT importer, then checks the computed digest against the stored digest. This establishes internal consistency with the supplied caption/media editions, not database authenticity, word accuracy, media content verification or publication permission. References, flags and digest strings are not authentication.

The transcript, graph, accessible record table and modal inspector share exact records. Source nodes retain their real evidence revisions; the derivative retains its supplied storage revision. Cue-view references are derived projections of that containing derivative edition, not fabricated independently persisted cue revisions. Inspectors show original half-open caption byte ranges, source hashes, media times and exact media references. Original caption bytes remain outside the generated HTML; only selected cue text and metadata are included. No media URLs or playback requests are created.

Up to 200 cues are shown per window, with full-import totals and next offset disclosed in the derivative inspector. All source bytes are validated before windowing, so changing hidden cues invalidates the stored digest. Graph summaries are bounded excerpts; the readable transcript and inspector retain full selected text. Overlapping times remain intact. Cue times are offsets into media, never invented wall-clock audit events; no agent activity, speech recognition, speaker identity, confidence or independently verified testimony is inferred.

Payloads remain untrusted literal text. Static HTML escapes both readable transcript cells and embedded graph data, and dynamically opened inspectors use text nodes. The host must authorize viewing/exporting the selected sensitive text and serve any resulting private file securely. The component makes no network, command, playback, publication or outreach calls. It does not create a public research release.

Tests use actual pinned Processing imports and executed JSDOM interactions: source/media/derivative bindings, unchanged source byte anchors, conflicting/foreign records, digest/byte tampering, bounded windows, inert markup and long-text/paged inspector alignment. These are not real-browser, screen-reader, network-service or deployed authorization acceptance. Live hosting, media playback with authorization, richer review/correction controls and accessibility qualification remain pending.

`docs/examples/private-caption-review.html` is a deterministic fictional example generated by `npm run example:captions`. Every record/edition in that fixture is fictional; it is not a live database snapshot or a public research output.
